# ONTAP — Campus Super App

## Portfolio / Data Science Showcase Description

---

**Project Title:** ONTAP - Unified Campus Experience Platform

**Overview:**
ONTAP is a full-stack super app that consolidates fragmented campus services into a single, intuitive platform. Inspired by Careem's unified service model, it addresses the pain point of students juggling multiple apps for everyday campus needs.

**Problem Statement:**
University students use 5-10 different platforms daily for buying textbooks, renting equipment, finding rides, and accessing academic support—leading to inefficiency and poor user experience.

**Solution:**
A mobile-first web application that integrates:
- **Peer-to-peer marketplace** for buying/selling campus essentials
- **Rental system** for textbooks, electronics, and equipment
- **Rideshare matching** for airport runs and city commutes
- **MindWave AI Suite** — Study Assistant, Wellness Coach, Smart Campus Guide

---

## Technical Implementation

| Layer | Technology |
|-------|------------|
| Frontend | React 18, React Router, Axios, CSS3 |
| Backend | Node.js, Express.js, REST APIs |
| Database | MongoDB, Mongoose ODM |
| AI Integration | OpenAI API, Custom prompt engineering |
| DevOps | Environment-based config, CORS, Proxy setup |

---

## Key Technical Challenges Solved

- Dynamic API routing for network/mobile access detection
- Real-time data seeding with relational user references
- Responsive UI adapting to Careem-style design system
- Cross-origin resource sharing for multi-device access
