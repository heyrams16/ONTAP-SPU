## Professional Description (Resume/Portfolio)

**ONTAP** is a full-stack web application designed to streamline campus life for university students. The platform integrates a peer-to-peer marketplace, equipment rentals, rideshare coordination, and AI-powered productivity tools into a single, Careem-inspired interface.

**Key Features:** Student marketplace, item rentals, campus rideshare, MindWave AI (study assistant, wellness coach, smart campus guide)

**Tech Stack:** React, Node.js, Express, MongoDB, Axios, REST APIs

**Role:** Full-stack development, UI/UX design, database architecture
